# Звук в промо-роликах: пак UI-звуков и классика

Ролики собираются из двух источников звука: **настоящие записанные сэмплы** на каждое действие в кадре и **классическая
музыка** фоном. Оба лежат вне репозитория (скачиваются скриптом в `scripts/promo/sfx/` и `scripts/promo/score/`,
эти папки в `.gitignore`) — в git попадают только код, лицензия и атрибуция.

```
python3 scripts/promo/sfx.py            # скачать пак и нарезать сэмплы + собрать музыкальный скор
python3 scripts/promo/sfx.py --force    # перекачать всё заново
```

## 1. UI-звуки — «UI Sound Pack 1» (ViRiX / David McKee)

| | |
|---|---|
| Источник | OpenGameArt, [UI Sound Pack 1](https://opengameart.org/content/ui-sound-pack-1) |
| Файл | `https://opengameart.org/sites/default/files/UI%20pack%201.zip` (3.3 МБ) |
| Автор | David McKee (ViRiX) — soundcloud.com/virix |
| Формат | 11 WAV, 16 бит, стерео, 44.1 кГц |
| Условия | бесплатно для любого использования, **но с обязательной атрибуцией** |

**Обязательная строка в кредитах** (дословно, как просит автор):

```
Some of the sounds in this project were created by David McKee (ViRiX) soundcloud.com/virix
```

Она есть в финальной карточке `credits` (`docs/promo/full/cards.html`, флаг `--tail`) и в конце каждого ролика —
в `me-<lang>-<aspect>.cues.txt` рядом лежит строка кредитов из `sfx.credits()`.

Из пака берётся транзиент — первые 30–400 мс — и режется в короткие вавки `scripts/promo/sfx/<cue>.wav`:

| cue | файл в паке | длина | где звучит |
|---|---|---|---|
| `key` | `MENU_Pick.wav` | 45 мс | каждая буква промпта (прорежено до ~12 в секунду) |
| `tick` | `MENU_Pick.wav` | 35 мс | слово модели появляется в кадре (очень тихо) |
| `click` | `MENU A_Select.wav` | 160 мс | Enter, отправка промпта, клик в браузере |
| `pick` | `MENU B_Select.wav` | 220 мс | стрелки в меню `/theme`, листание маркетплейса |
| `back` | `MENU B_Back.wav` | 200 мс | «назад» / закрытие модалки |
| `msg` | `MESSAGE-B_Accept.wav` | 420 мс | сообщение с телефона прилетает на ПК |
| `pop` | `ALERT_Appear.wav` | 300 мс | файл появился, карточка в кадре, логотип |
| `gone` | `ALERT_Dissappear.wav` | 260 мс | уход сцены, финальный фейд |
| `error` | `ALERT_Error.wav` | 450 мс | (в роликах не используется — на всякий случай) |
| `now` | `ETRA.wav` | 400 мс | установщик пошёл: `curl … \| sh` |

## 2. Музыка — Шопен, записи Musopen (CC0)

| | |
|---|---|
| Источник | Internet Archive, [Musopen — The Complete Chopin Collection](https://archive.org/details/musopen-chopin) |
| Прямые файлы | `https://archive.org/download/musopen-chopin/<файл>.mp3` (поддерживает Range, 206) |
| Лицензия | [CC0 1.0](http://creativecommons.org/publicdomain/zero/1.0/) — public domain, атрибуция не требуется (но приятна) |

Скор собирается из трёх ноктюрнов: берутся спокойные фрагменты, каждый со своими фейдами, и склеиваются через
`acrossfade` (2.5 с) — шва не слышно.

| ключ | файл | откуда | длина | в кредитах |
|---|---|---|---|---|
| `main` | `NocturneOp9No2.mp3` | 0:00 | 30 с | Chopin — Nocturne Op. 9 no. 2 |
| `b` | `Nocturne Op. 27 no. 1 in C sharp minor.mp3` | 0:24 | 28 с | Chopin — Nocturne Op. 27 no. 1 |
| `c` | `Nocturne Op. 48 no. 2 in F sharp minor.mp3` | 0:24 | 28 с | Chopin — Nocturne Op. 48 no. 2 |
| `short` | `NocturneOp9No2.mp3` | 0:00 | 26 с | для роликов короче минуты |

Ролик до 60 с получает `["short"]` (один ноктюрн с начала), длиннее — `["main","b","c","b"]` (~86 с музыки, с запасом).

## 3. Как звук попадает на таймлайн

Сцена сама говорит, что в ней произошло и когда (`sfx.Timeline`), поэтому клик всегда совпадает с картинкой:

- **терминал** (`termrec.py`) — в `.cast` лежит каждый байт и его время: `_typed_from_cast` находит набранные строки
  (буква за буквой), Enter и стрелки/пробел. Клик — по буквам, `click` — на отправку, `pick` — на стрелки;
- **сцена «агент пишет страницу»** (`scene_page.py`) — это настоящий `me.py --rpc`: мок пишет строку на каждое
  стримленное слово (`mock_promo.cue`), время считается от кадра 0 сцены (`mock_promo.FRAME0`), плюс метки набранного
  промпта и `pop` в момент, когда агент закончил;
- **браузер** (`scenes_web.py`) — `Mark`: клики, набранный текст, момент, когда сообщение долетело до второго окна;
- **карточки** — `pop` на появление логотипа, `gone` на финальный фейд.

Дальше `sfx.mix`:

1. каждый cue — свой вход, `adelay` по времени, громкость из `CUE_GAIN`;
2. музыка: фейд-ин 1.5 с, фейд-аут 2.5 с, `lowpass 14 кГц` (мягче, не спорит с речью в голове);
3. `sidechaincompress`: музыка приседает на −8 дБ, пока играют клики (порог 0.02, release 320 мс) — без статичного дакинга;
4. `alimiter` и `loudnorm` до −16 LUFS (норма для веба и соцсетей).

## 4. Если сети нет

`sfx.ensure()` ничего не ломает: нет пака или скора — ролик соберётся с одним звуком/без звука, а в stderr будет строка
с причиной. `PROMO_NO_MUSIC=1` — собрать вообще без музыки (звуки останутся), `PROMO_MUSIC=0.5` — сделать фон громче.
