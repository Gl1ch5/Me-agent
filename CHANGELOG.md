# Changelog

Обновление: `/update` в терминале — или заново команда установки с сайта.

## 0.6.1 — 2026-10-14
- Исправлено: `me` не запускался на Python 3.8–3.11 (частый случай на Windows). Теперь CI проверяет Windows, macOS и Linux на Python 3.8, 3.11 и 3.13.
- Картинки: `ctrl+v`, `alt+v` или правый клик вставляют изображение из буфера обмена (Windows, Linux X11/Wayland, macOS); перетащенный в терминал файл-картинка прикрепляется к сообщению как `[image #1]`.
- Копирование текста в терминале: выделите мышью — текст сразу в буфере обмена. `alt+c` — последний ответ, `/copy` — блок кода или весь диалог. Работает в cmd.exe, Windows Terminal и на Linux.
- Многострочная вставка в классическом cmd.exe больше не отправляет каждую строку отдельным сообщением.
- Меньше мерцания в консоли Windows: неизменившиеся кадры не перерисовываются, длинные сессии рисуются быстрее.
- Старт без ожидания сети: синхронизация с облаком идёт в фоне.
- Агент дешевле: старые большие выводы инструментов и картинки не пересылаются модели на каждом шаге, чтение файлов ограничено, лишний «шаг самопроверки» после правки документации убран.
- Честная статистика хода: шаги, реальный размер контекста, отправлено ↑ (с долей кэша) и ↓. Если провайдер не присылает usage — токены оцениваются, а не показываются нулём.
- Надёжность: повтор запроса при 429/5xx/обрыве соединения, ошибки внутри потока провайдера показываются, `Esc` мгновенно прерывает даже «молча думающую» модель.
- Пути и команды инструментов всегда считаются от папки проекта сессии; команды на Windows не открывают окна консоли; можно выбрать оболочку PowerShell или Git Bash (`settings.shell`).
- Агенты и навыки, сохранённые с переводами строк Windows (CRLF), теперь читаются.
- Быстрее: синхронизация и рабочие области не перечитывают неизменённые файлы.
- Новое: **me IDE** — редактор на основе VS Code (VSCodium) со встроенным агентом, портативный для Windows и Linux, и **расширение для VS Code / Cursor** (`me-agent.vsix`): панель агента рядом с кодом, «спросить про выделенное», «исправить проблемы файла».
- Веб-приложение и приложение для Windows: чаты сгруппированы по папкам проектов (как в Codex), «+» — новый чат в нужном проекте, открыть другую папку можно прямо из боковой панели; в приложении для Windows — настоящий диалог выбора папки.
- Приложение для Windows: исправлен запуск (сервер внутри падал без консоли, окно оставалось пустым), только один экземпляр.
- Android: работает кнопка «прикрепить» (фото и файлы), новый режим «на этом телефоне» — агент запускается в Termux; долгое нажатие «назад» переключает облако/телефон.
- Windows: инструменты не падают, если файл и проект на разных дисках (C: и D:); файлы с переводами строк LF больше не превращаются в CRLF при правках и `/undo`.
- Сайт: раздел «Приложения» со ссылками на все клиенты.

## 0.6.0 — 2026-10-13
- Во встроенных остался один агент — `code`, теперь универсальный: чинит, отлаживает, ревьюит, планирует, пишет документацию и ищет в сети по запросу, без переключения режимов. Остальные (`design`, `plan`, `review`, `debug`, `docs`, `research`, `me`, `security`, `devops`, `tester`…) — в маркетплейсе: `/agent` → «+ more agents».
- Новый формат агентов: в файле агента можно описать свои CLI-инструменты строкой `cli.<имя>: описание | команда с {параметрами} | параметр, другой=по_умолчанию`. Они появляются у модели как `<агент>_<имя>`, идут через обычные разрешения и рисуются карточкой с цветным статус-баром (цвет и значок — поля `color` и `icon` агента): бегущая полоса и последняя строка вывода во время работы, полная полоса и код выхода в конце, красная — если команда упала. В терминале и в вебе.
- Веб-интерфейс (локальный и облачный): все слэш-команды, меню по `/` с подсказками и стрелками — `/agent`, `/model`, `/effort`, `/prompt`, `/skills`, `/theme`, `/perm`, `/yolo`, `/cost`, `/todo`, `/copy`, `/compact`, `/autocompact`, `/undo`, `/goal`, `/init`, `/new`, `/sessions`, `/workspace`, `/sync`, `/help`. То, что настраивается на сайте (модели, провайдеры, плагины, 2FA), открывает аккаунт.
- Агенты маркетплейса `review`, `debug`, `docs`, `security`, `devops`, `tester` получили готовые CLI-инструменты.

## 0.5.13 — 2026-10-12
- Windows: прокрутка колёсиком работает в cmd.exe и Windows Terminal, набор текста не ломается.
- Windows: Esc и таймаут завершают всё дерево процессов команды, а не только cmd.exe.
- Windows: вывод команд на русской Windows больше не превращается в кракозябры (кодировка cp866).
- Windows: после выхода консоль возвращается в исходный режим; эмодзи при вводе не ломаются.
- Агент делает только то, что попросили: на вопрос — ответ, без лишних файлов, команд и рефакторинга. AGENTS.md больше не создаётся сам.
- Агент знает, какой shell у него (cmd.exe на Windows) и не пишет Linux-команды.
- Сообщения из очереди доходят до агента после каждого шага (поиск, чтение, команда), а не в конце всего ответа.
- После ответа todo-список убирается, прерванные инструменты не крутятся вечно.
- Исправлено: два хода агента одновременно (/goal, /init + очередь), `/undo` после сжатия истории, падение отрисовки в маленьком окне, курсор в длинном вводе, порча путей внутри файлов, обрыв хода на кривых аргументах инструментов.
- Настройки и сессии сохраняются надёжно, даже если файл держит антивирус или OneDrive.
- Ошибки отрисовки пишутся с подробностями в `~/.me/render-error.log`.
