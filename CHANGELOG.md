# Changelog

## 0.7.0 — 2026-10-19
Сравнили с OpenCode и pi на той же модели и закрыли разрыв: надёжность, инструменты, Windows.

**Копирование и мышь**
- Выделение мышью прямо в ленте: тяните — текст копируется, как только отпустите кнопку. Двойной клик — слово, тройной — строка. Копируется сам текст: без рамок, отступов, хвостовых пробелов и без переносов, которые добавил терминал (абзац остаётся одной строкой, код — с правильными отступами).
- Буфер обмена настоящий: на Windows — системный (WinAPI), на macOS — pbcopy, на Linux — wl-copy/xclip/xsel, в Termux — termux-clipboard-set; по SSH — через терминал (OSC 52). Раньше `/copy` в cmd.exe не работал вовсе.
- Правый клик вставляет из буфера (Windows), `ctrl+v` и `shift+insert` — тоже. Клик по карточке инструмента раскрывает её.
- `/copy code` — последний блок кода из ответа, `/copy 2` — предыдущий ответ.
- Мышь снова включена по умолчанию везде; в `/config` можно вернуть выделение самого терминала. Строки больше не забиваются пробелами до края — даже обычное выделение терминала копирует чистый текст.

**Windows**
- Новый ввод с консоли (как в crossterm): клавиши читаются по кодам, а не escape-последовательностями — стрелки не превращаются в «Esc + [A», буквы не теряются, эмодзи и Alt+цифры работают. `shift+enter` — новая строка.
- Вставка многострочного текста больше не отправляет его по строчке.
- Команды агента идут через Git Bash, если он установлен (модели пишут bash намного лучше), иначе PowerShell 7 / PowerShell, и только потом cmd.exe. Агенту в промпте сказано, какой именно shell.
- Запущенные агентом программы получают свою скрытую консоль: не воруют нажатия клавиш и не ломают режим консоли (после них больше нет «←[38;2;…» на экране).
- Правка файлов сохраняет переводы строк (CRLF/LF), кодировку (в т.ч. cp1251) и BOM. Раньше любая правка на Windows переписывала весь файл в CRLF.

**Агент: качество и надёжность**
- Ошибки API (429, перегрузка, 5xx, обрыв соединения, ошибка посреди ответа) повторяются с паузой — ход больше не обрывается. Частично показанный ответ неудачной попытки убирается.
- Переполнение контекста: история сжимается и запрос повторяется сам. Сжатие теперь работает и внутри одной длинной задачи.
- Рассуждения модели между шагами сохраняются: `reasoning_content` (DeepSeek, Kimi, Qwen), `reasoning_details` (OpenRouter), подписи мыслей Gemini, зашифрованные рассуждения в Responses API (GPT-5). Модели больше не «забывают», что думали, между вызовами инструментов.
- Ответ, обрезанный лимитом токенов, продолжается сам; обрезанные аргументы инструмента дают модели понятную подсказку вместо «неверный JSON». Пустой ответ запрашивается повторно. Повтор одного и того же вызова три раза подряд останавливается подсказкой.
- Esc прерывает зависший поток сразу, а не после таймаута.
- Чтение файла ограничено 50k символов с подсказкой `offset`; «нет такого файла» предлагает похожие имена.
- `edit` прощает типичные промахи моделей: кавычки-«ёлочки» и тире, лишние пробелы в конце строк, неверный отступ (новый текст сдвигается под файл), имена параметров других агентов (`old_string`, `oldText`…).
- `ls` по папке показывает её содержимое, глобы понимают `{ts,tsx}` и не лезут в node_modules. `grep` сообщает об ошибке в регулярке вместо «ничего не найдено», понимает шаблоны с `-`.
- `bash`: `background=true` для серверов и вотчеров, таймаут — честная ошибка, цвета и прогресс-бары вычищаются из вывода, длинный вывод целиком сохраняется в файл.
- Подхватываются AGENTS.md / CLAUDE.md из родительских папок (монорепо).
- Описания инструментов и системный промпт стали точнее (≈2k токенов вместо ≈1.5k).

**Прочее**
- `/new` в терминале очищает экран — старый диалог больше не висит. В облачном вебе новый чат больше не показывает прошлый.
- Копирование в вебе работает и по LAN-адресу (без https).
- Навык с неустановившейся зависимостью сообщает причину и пробует снова, а не падает молча.

## 0.6.0 — 2026-10-13
- Во встроенных остался один агент — `code`, теперь универсальный: чинит, отлаживает, ревьюит, планирует, пишет документацию и ищет в сети по запросу, без переключения режимов. Остальные (`design`, `plan`, `review`, `debug`, `docs`, `research`, `me`, `security`, `devops`, `tester`…) — в маркетплейсе: `/agent` → «+ more agents».
- Новый формат агентов: в файле агента можно описать свои CLI-инструменты строкой `cli.<имя>: описание | команда с {параметрами} | параметр, другой=по_умолчанию`. Они появляются у модели как `<агент>_<имя>`, идут через обычные разрешения и рисуются карточкой с цветным статус-баром (цвет и значок — поля `color` и `icon` агента): бегущая полоса и последняя строка вывода во время работы, полная полоса и код выхода в конце, красная — если команда упала. В терминале и в вебе.
- Веб-интерфейс (локальный и облачный): все слэш-команды, меню по `/` с подсказками и стрелками — `/agent`, `/model`, `/effort`, `/prompt`, `/skills`, `/theme`, `/perm`, `/yolo`, `/cost`, `/todo`, `/copy`, `/compact`, `/autocompact`, `/undo`, `/goal`, `/init`, `/new`, `/sessions`, `/workspace`, `/sync`, `/help`. То, что настраивается на сайте (модели, провайдеры, плагины, 2FA), открывает аккаунт.
- Агенты маркетплейса `review`, `debug`, `docs`, `security`, `devops`, `tester` получили готовые CLI-инструменты.

- Ошибки отрисовки пишутся с подробностями в `~/.me/render-error.log`.
