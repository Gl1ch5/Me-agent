## 0.7.0 — 2026-10-19
Сравнили с OpenCode и pi на той же модели и закрыли разрыв: надёжность, инструменты, Windows. Плюс новое приложение — **me studio**.

**me studio — много агентов сразу (как приложение Codex)**
- Отдельное приложение (`me studio` или `me-studio.exe`): слева проекты, под ними задачи. Каждая задача — свой агент, их можно запускать параллельно.
- Режим **worktree**: задача работает в своём git worktree на своей ветке `me/…`, ваш рабочий каталог не трогается, пока вы не примените результат. Режим **local** — прямо в папке проекта.
- Ход задачи вживую: ответы, мысли, шаги инструментов с выводом, запросы разрешений, todo. Можно дописать задаче сообщение на ходу.
- Ревью: дифф каждого файла; **Применить к проекту** (3-way патч), **Коммит**, **Пуш ветки**, **Отбросить** (удаляет worktree и ветку); для local — **Откатить ход**. Терминал в папке задачи, своя модель и effort на задачу, все темы me.
- Задачи — обычные сессии me: синхронизируются с аккаунтом. Без pywebview приложение открывается в браузере.

**Вставка и копирование в терминале**
- Большая вставка больше не роняет me: раньше при сбое остаток вставленного текста уходил в cmd.exe, и cmd выполнял каждую строку как команду. Теперь ошибка в обработке клавиши записывается в `~/.me/error.log` и показывается, а при выходе непрочитанный ввод консоли сбрасывается.
- Вставка больше 1500 символов или 15 строк показывается одним маркером `[paste #1 · N lines]` и разворачивается при отправке; длинные сообщения в ленте показывают первые 20 строк.
- Половинки эмодзи и управляющие символы во вставке больше не ломают экран и историю.
- Выделение мышью прямо в ленте: тяните — текст копируется, как только отпустите кнопку. Двойной клик — слово, тройной — строка. Копируется сам текст: без рамок, отступов, хвостовых пробелов и без переносов, которые добавил терминал.
- Буфер обмена настоящий: на Windows — системный (WinAPI), на macOS — pbcopy, на Linux — wl-copy/xclip/xsel, в Termux — termux-clipboard-set, в WSL — через PowerShell; по SSH — через терминал (OSC 52).
- `ctrl+v` / `alt+v` / правый клик вставляют текст, а если в буфере картинка — прикрепляют её; перетащенный файл-картинка прикрепляется как `[image #1]`. `alt+c` — скопировать последний ответ, `/copy` — ответ, блок кода или весь диалог.
- Мышь снова включена по умолчанию везде; в `/config` можно вернуть выделение самого терминала.

**Windows**
- Новый ввод с консоли (как в crossterm): клавиши читаются по кодам, а не escape-последовательностями — стрелки не превращаются в «Esc + [A», буквы не теряются, эмодзи и Alt+цифры работают. `shift+enter` — новая строка.
- Команды агента идут через Git Bash, если он установлен (модели пишут bash намного лучше), иначе PowerShell 7 / PowerShell, и только потом cmd.exe. Агенту в промпте сказано, какой именно shell.
- Запущенные агентом программы получают свою скрытую консоль: не воруют нажатия клавиш и не ломают режим консоли.
- Правка файлов сохраняет переводы строк (CRLF/LF), кодировку (в т.ч. cp1251) и BOM.

**Агент: качество и надёжность**
- Ошибки API (429, перегрузка, 5xx, обрыв соединения, ошибка посреди ответа) повторяются с паузой; частично показанный ответ неудачной попытки убирается.
- Переполнение контекста: история сжимается и запрос повторяется сам. Сжатие работает и внутри одной длинной задачи.
- Рассуждения модели между шагами сохраняются: `reasoning_content` (DeepSeek, Kimi, Qwen), `reasoning_details` (OpenRouter), подписи мыслей Gemini, зашифрованные рассуждения в Responses API (GPT-5).
- Ответ, обрезанный лимитом токенов, продолжается сам; обрезанные аргументы инструмента дают модели понятную подсказку. Пустой ответ запрашивается повторно. Повтор одного и того же вызова три раза подряд останавливается подсказкой.
- `edit` прощает типичные промахи моделей: кавычки-«ёлочки» и тире, лишние пробелы, неверный отступ, имена параметров других агентов (`old_string`, `oldText`…).
- `ls` по папке показывает её содержимое, глобы понимают `{ts,tsx}`. `grep` сообщает об ошибке в регулярке. `bash`: `background=true` для серверов, честный таймаут, вывод без цветов и прогресс-баров, длинный вывод целиком в файле.
- Подхватываются AGENTS.md / CLAUDE.md из родительских папок (монорепо). Описания инструментов и системный промпт точнее (≈2k токенов).

**Прочее**
- `/new` в терминале очищает экран; в облачном вебе новый чат больше не показывает прошлый.
- Веб: строка статистики хода снова видна (раньше падала с ошибкой в фоне); копирование работает и по LAN-адресу.
- Навык с неустановившейся зависимостью сообщает причину и пробует снова.

## 0.6.1 — 2026-10-15
- Windows: мышь (колёсико) по умолчанию выключена — ввод идёт через классический ридер, буквы больше не теряются. Включить можно в `/config`.
- Исправлено: `me` не запускался на Python 3.8–3.11 (частый случай на Windows). Теперь CI проверяет Windows, macOS и Linux на Python 3.8, 3.11 и 3.13.
- Картинки: `ctrl+v`, `alt+v` или правый клик вставляют изображение из буфера обмена (Windows, Linux X11/Wayland, macOS); перетащенный в терминал файл-картинка прикрепляется к сообщению как `[image #1]`.
- Копирование текста в терминале: выделите мышью — текст сразу в буфере обмена. `alt+c` — последний ответ, `/copy` — блок кода или весь диалог. Работает в cmd.exe, Windows Terminal и на Linux.
- Многострочная вставка в классическом cmd.exe больше не отправляет каждую строку отдельным сообщением.
- Меньше мерцания в консоли Windows: неизменившиеся кадры не перерисовываются, длинные сессии рисуются быстрее.
- Старт без ожидания сети: синхронизация с облаком идёт в фоне.
- Агент дешевле: старые большие выводы инструментов и картинки не пересылаются модели на каждом шаге, чтение файлов ограничено, лишний «шаг самопроверки» после правки документации убран.
- Честная статистика хода: шаги, реальный размер контекста, отправлено ↑ (с долей кэша) и ↓. Если провайдер не присылает usage — токены оцениваются, а не показываются нулём.
- Надёжность: повтор запроса при 429/5xx/обрыве соединения, ошибки внутри потока провайдера показываются, `Esc` мгновенно прерывает даже «молча думающую» модель.
- Пути и команды инструментов всегда считаются от папки проекта сессии; команды на Windows не открывают окна консоли; можно выбрать оболочку PowerShell или Git Bash (`settings.shell`).
- Агенты и навыки, сохранённые с переводами строк Windows (CRLF), теперь читаются.
- Быстрее: синхронизация и рабочие области не перечитывают неизменённые файлы.
- Новое: **me IDE** — редактор на основе VS Code (VSCodium) со встроенным агентом, портативный для Windows и Linux, и **расширение для VS Code / Cursor** (`me-agent.vsix`): панель агента рядом с кодом, «спросить про выделенное», «исправить проблемы файла».
- Веб-приложение и приложение для Windows: чаты сгруппированы по папкам проектов (как в Codex), «+» — новый чат в нужном проекте, открыть другую папку можно прямо из боковой панели; в приложении для Windows — настоящий диалог выбора папки.
- Приложение для Windows: исправлен запуск (сервер внутри падал без консоли, окно оставалось пустым), только один экземпляр.
- Android: работает кнопка «прикрепить» (фото и файлы), новый режим «на этом телефоне» — агент запускается в Termux; долгое нажатие «назад» переключает облако/телефон.
- Windows: инструменты не падают, если файл и проект на разных дисках (C: и D:); файлы с переводами строк LF больше не превращаются в CRLF при правках и `/undo`.
- Сайт: раздел «Приложения» со ссылками на все клиенты.

В терминале и в вебе.
- Веб-интерфейс (локальный и облачный): все слэш-команды, меню по `/` с подсказками и стрелками — `/agent`, `/model`, `/effort`, `/prompt`, `/skills`, `/theme`, `/perm`, `/yolo`, `/cost`, `/todo`, `/copy`, `/compact`, `/autocompact`, `/undo`, `/goal`, `/init`, `/new`, `/sessions`, `/workspace`, `/sync`, `/help`.
