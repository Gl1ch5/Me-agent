background & scheduled tasks

"Do X and tell me when it's done": a task runs in a sandbox even after you close the page, then reports to Telegram (or a push). Add a schedule to repeat it.

telegram

Your own bot: create one with @BotFather (/newbot), paste its token here, then connect. Chat with your agent from it (text or voice), and the agent's notify tool sends you messages and files through it.

notifications

Push to this browser or phone (install the web app to the home screen on iOS): "done" when a task finishes while you are away, "waiting for you" when the agent asks.

github

A fine-grained token (contents + pull requests: read/write). The agent can then clone, branch, commit, push and open PRs; clone a repo into a workspace from the workspaces tab.

local web UI

Same interface, agent on your own machine: me web → opens localhost:8080. On Android use Termux: pkg install python, then the install command.

plugins

Plugins change me itself — new commands, tools, keybindings, UI. They run with full access, install only what you trust. Restart me to apply.

workspaces

Project folders synced between your machines and the cloud. Code files ≤ 1 MB; heavy, binary and .gitignored files stay local.
