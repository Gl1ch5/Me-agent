tiny on purpose

  
Most agents spend 10–20k tokens before you say hello. me starts under 1k: a sharp system prompt and a few compact tools, web search included. Everything else loads only when it's needed.

  

    
01one file
Stdlib Python. Read it, fork it, run it anywhere Python runs: Linux, macOS, Windows, a server, a Raspberry Pi.

    
02cloud sync
Config, providers, keys, system prompt, skills and full chat history follow your account. New laptop? me → log in → done.

    
03any model
Any OpenAI-compatible API: chat/completions or responses, reasoning effort, streaming thinking, custom names and context sizes.

    
04skills, not MCP
A skill is one .py file: instructions plus actions. About 15 tokens idle. MCP servers also work, loaded lazily the same way.

    
05goals and plans
A live todo checklist in every UI. /goal works until the goal is done and verified, or tells you exactly what blocks it.

    
06safe edits
A checkpoint per turn gives you /undo. The web UI shows a diff to keep or revert. Permissions: read-only, ask, or full.

    
07cloud sandbox
Start in the terminal, continue in the browser or Telegram. The session and project files follow you, isolated on the server.

    
08web app on your phone
me web locally, or the cloud /app as an installable PWA with attachments and push when a task is done.

    
09background and preview
"Do X and notify me": tasks keep running after you close the page. The site the agent built opens on your phone by link.

    
10plugins and voice
Plugins change me itself: commands, tools, keys, themes. Hold space to dictate with Groq Whisper.

    
11your own Telegram bot
Every account sets its own bot. The agent's notify tool sends you messages and files.

    
122FA if you want
Username and password by default. Attach Google Authenticator, Aegis or 1Password in one command.

skills are just python

  
The model sees one line per skill. When it needs one, it loads the guide and calls actions. Each call shows up as a live card with status, progress and logs, then collapses into a one-liner.

  


"""
name: github
description: issues & PRs on GitHub
icon:
color: magenta
env: GITHUB_TOKEN
---
Call list_prs before labeling.
"""

@action
def list_prs(ctx, repo: str):
    "Open PRs of a repo"
    return ctx.http.get(f"…/repos/{repo}/pulls")

@action(confirm=True)
def label(ctx, repo: str, nums: list):
    "Label many PRs"
    for n in ctx.progress(nums, "labeling"):
        ctx.log(f"#{n}")

open source, and yours to run

  
Everything here is open: the agent, the web UI, the server and the deploy files. Anyone can run the server part on their own machine, so you never have to trust us with your data.

  

    
01read it
The client is me.py, built from plain files in src/. The server is server/ (FastAPI + SQLite). No hidden parts.

    
02run your own
Install the backend on any Linux box with Python, point ME_SERVER at it and your devices sync there instead of here.

    
03plain about data
The hosted server keeps your synced config, keys and chats unencrypted, and its operator can read them. Not okay for you? Run your own server.

    
04locked down
Passwords and session tokens are hashed, 2FA is optional, cloud sandboxes run isolated. Read marketplace skills before you install them.
